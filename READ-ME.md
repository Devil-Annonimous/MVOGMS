# 🛒 Online Multivendor Grocery Shop Management System

A PHP & MySQL-based web application designed to manage an online grocery marketplace where multiple vendors can register, upload products, and sell to customers through a unified platform. This system is tailored for local Bangladeshi grocery businesses to enable affordable and scalable e-commerce solutions.

---

## 📌 Features

- 🔐 Secure user registration and login (admin, vendor, customer)
- 🛍️ Vendor dashboard for product upload, stock management
- 🛒 Customer panel with shopping cart and order tracking
- 🧑‍💼 Admin panel for vendor/user management and system monitoring
- 📊 Product categorization, search, and dynamic pricing
- 📦 Order history and real-time status updates

---

## ⚙️ Technologies Used

- **Frontend:** HTML5, CSS3, Bootstrap/Tailwind
- **Backend:** PHP (OOP)
- **Database:** MySQL
- **Local Server:** XAMPP / LAMP
